# NCO / QMD 与 GregTech 材料同化报告

日期：2026-10-17（二阶段）

范围：只讨论 NuclearCraft: Overhauled（NCO）、Quantum Minecraft Dynamics（QMD）与现有
GTCE-TJ 材料/配方的衔接。不涉及 Minespace 模块拆分、天体表或星图。

## 1. 参考 Omnifactory 的结论

本次对照了 `Omnifactory-1.3.2.zip` 的 `overrides/scripts/Nuclearcraft.zs`。它处理核电的主要做法是：

- 清空 NCO 的通用加工机器配方（合金炉、化学反应器、离心机、电解槽等），通用加工交给 GT。
- 保留 NCO 的反应堆、燃料、裂变产物和辐射相关内容。
- 把能对应的材料收敛到 GT 物品，再用 JEI 的 `removeAndHide` 隐藏重复条目。
- 对 GT 已有、NCO 又需要的同位素，用 GT 热离心机增加显式转换配方。

本项目采用同样的分工，但不照搬“清空机器配方”：NCO 的处理器仍保留，通用加工已经复制进 GT
机器；只把材料身份和配方输入输出收敛到 GT。

## 2. 材料归属边界

| 类别 | 归属 | 例子 |
| --- | --- | --- |
| 普通稳定材料 | GT | 铜、锡、铅、镍、钛、钨、不锈钢、石墨、硫、盐、碘、硅 |
| GT 已有同位素 | GT | U-235、Np-237、Pu-241、Am-241/243、Cm-245/246/247、Bk-247、Cf-251/252 |
| NCO 独有同位素 | NCO | U-233/238、Pu-238/239/242、Am-242、Cm-243、Bk-248、Cf-249/250 |
| NCO 裂变产物 / 燃料形式 | NCO | 锶-90、铯-137、钷-147、碳化物/氧化物/氮化物/ZA 燃料 |
| NCO 机器部件 | NCO | 气体冷却器、冷却器端口、裂变外壳 |
| QMD 粒子 / 反物质 / 源 | QMD | 反物质单元、正电子素、μ子素、粒子源 |

判断规则只有一条：**GT 已经有同名或等价物品时才同化；GT 没有对应物的 NCO/QMD 专属内容保留。**
这里不为了“看起来统一”而给 NCO/QMD 的专属物品硬造 GT 物品。

## 3. 代码实现

### 3.1 `MinespaceMaterialRepoint`

- 维护 `mod 物品 id -> GT 物品` 的目标表，目标始终优先选择 `gregtech:` 命名空间。
- 修正 GT 机器配方的主输出和 **chanced outputs**。此前只改主输出，导致 NCO 锡粉等概率产出残留。
- 修正 GT 机器配方输入：一个矿物词典名里只要包含 GT 物品，且其余成员都是已映射的模组副本，
  就把整个输入收敛为 GT 物品。
- 修正工作台输入，并用同一规则删除已经没有任何消费者的重复产出配方。
- `addNuclearStableTargets` 只在矿物词典名中确实存在 `gregtech:` 物品时才建立映射，避免把
  NCO 独有材料映射成自身。

### 3.2 `MinespaceNuclearMaterialRewrite`

- 处理 NCO 自己的 `BasicRecipe`，包括直接 `ItemIngredient`、`ChanceItemIngredient` 和
  `OreIngredient` 输出。
- 输出数量保持不变：`OreIngredient.stackSize` 会写回 GT 物品的堆叠数量。
- 输入侧只在“这个矿物词典名已经完全统一”时改为精确 GT 物品，混合了其他模组材料的名字保持不变。
- 在 `loadComplete` 再执行一次，接住 NCO/QMD 在 `postInit` 后才注册的配方。

### 3.3 NCO 处理器迁移的槽位校验

之前 `MinespaceNuclearMaterials` 直接提交配方，GT 会对槽位不匹配的配方逐条打印
`Invalid amount of recipe inputs`，一次启动能刷出数万行，实际却没有注册。现在按目标
`RecipeMap` 的最小/最大物品、流体、输出槽位先做校验，并修正了三处映射：

| NCO 处理器 | 原目标 | 问题 | 现在 |
| --- | --- | --- | --- |
| `melter` | GT 提取机 | 提取机没有“物品 -> 流体”槽位 | GT 流体提取机 |
| `pressurizer` | GT 卷板机 | 卷板机需要第二个非消耗形状槽 | 卷板机 + 非消耗电路标记 |
| `ingot_former` | GT 流体固化机 | 流体固化机需要一个模具槽 | 流体固化机 + 非消耗电路标记 |
| `extractor` | GT 提取机 | 提取机没有流体输出 | GT 化学反应器 |

现在 15 个 NCO 处理器共 3293 条配方全部迁入 GT，0 条因槽位跳过。

### 3.4 QMD 可选加载

QMD 的改写拆到 `MinespaceQmdRecipeRewrite`，由 NCO 侧通过反射调用。这样只安装 NCO、不安装
QMD 时，`MinespaceNuclearMaterialRewrite` 不会因为缺少 QMD 类而加载失败。

### 3.5 诊断

`MinespaceDiagnostics` 新增 `material-targets.csv`，记录全部 `源物品 -> GT 目标`。
`tools/audit-nuclear-residue.py` 直接读取导出目录，统计 NCO/QMD 物品在 GT、NCO、QMD 配方中的
产出和消耗残留。

### 3.6 新建 GT 材料

`MinespaceNuclearGtMaterials` 在 GT 的材料初始化阶段补建了 NCO/QMD 缺少的材料，共
**68 个新建 + 1 个复用（CobaltOxide）**：

| 类别 | 数量 | 形式 |
| --- | ---: | --- |
| 合金 / 聚合物 | 24 | 锭、粒、块、粉、熔融流体 |
| 氧化物 | 9 | 锭、粒、块、粉、熔融流体 |
| 化合物 / 超导前驱体 | 27 | 粉 |
| 宝石 | 5 | 宝石和粉 |
| 缺失形态 | 4 | Boron 锭、CobaltOxide 锭、Mercury 锭、Fluorite 宝石 |

最后 4 个是“基础材料已在 GT、但形态缺失”的情况：GT 的硼、氧化钴、萤石是粉，汞是流体。
它们用独立的 Form 材料生成缺少的锭/宝石形态，再通过 `OreDictionary.registerOre` 挂回
`ingotBoron`、`ingotCobaltOxide`、`ingotMercury`、`gemFluorite`，因此 NCO/QMD 的原有物品
仍能 1:1 收敛到 GT。

带数字后缀的独有核素（Sr-90、U-233/238、Pu-238/239/242、Np-236、Am-242、Cm-243、
Bk-248、Cf-249/250 等）**没有**新建 GT 材料。GT 的材料前缀注册对这类名字会生成没有
前缀/材料的元物品，CraftTweaker 的 `MetaItemBracketHandler` 在遍历时抛出
`NullPointerException`。这些核素继续由 NCO 持有；GT 已经自带的 U-235、Pu-241、
Am-241/243、Cm-245/246/247、Bk-247、Cf-251/252、Np-237 仍按前面的稳定材料映射统一。

材料 ID 仍从 GT 的 1000 槽登记表中从低到高寻找空位；本次注册后还剩 **138 个空位**。

### 3.7 NCO 块锭转化

NCO 自己注册了 26 条 `ingot_block` / `ingot_block2` 的 3x3 工作台配方（9 锭 -> 1 块）。
这些配方原来绕过了 GT 的压缩流程，而且在材料统一后仍使用 NCO 块物品。

修复：

- 删除全部 26 条 NCO 工作台块配方（注册为 `DummyRecipe`）。
- 为 26 个 NCO 块各补一条 GT 压缩机配方（9 个 GT 锭 -> NCO 块）。
- 为 26 个 NCO 块各补一条 GT 解包机配方（NCO 块 + 电路 -> 9 个 GT 锭）。
- 输入锭显式选择 `gregtech:` 物品，避免铜/锡/铅/镁再次落到 Forestry / Galaxy Space 的副本。
- 这些配方在所有“不可达机器配方”清理之后注册，否则解包机会把 NCO 块误判为已统一掉的输入而删除。

现在块锭转化只能通过 GT 压缩机/解包机完成。

### 3.8 电池与板材平衡

电池容量和传输速率按 GT 的 4 倍电压阶梯重新定标。旧值中贫铀锂离子电池块是
512 MRF（约 128M EU），现在降到 102.4 MRF（25.6M EU），与 GT IV 级电池一致；
精英锂离子电池块从 2.048 BRF 降到 409.6 MRF。

| 电池 | 容量（RF） | 传输（RF/t） | 等效 EU |
| --- | ---: | ---: | ---: |
| 基础伏打电堆 | 400,000 | 512 | 100,000 |
| 高级伏打电堆 | 1,600,000 | 2,048 | 400,000 |
| 贫铀伏打电堆 | 6,400,000 | 8,192 | 1,600,000 |
| 精英伏打电堆 | 25,600,000 | 32,768 | 6,400,000 |
| 基础锂离子电池块 | 6,400,000 | 8,192 | 1,600,000 |
| 高级锂离子电池块 | 25,600,000 | 32,768 | 6,400,000 |
| 贫铀锂离子电池块 | 102,400,000 | 131,072 | 25,600,000 |
| 精英锂离子电池块 | 409,600,000 | 524,288 | 102,400,000 |

单格锂离子电池从 8 MRF 降到 6.4 MRF（1.6M EU，HV），传输从 80,000 RF/t
降到 8,192 RF/t。

电池配方也全部改为 GT 组装机，不再用 NCO 零件直接拼：

| 产物 | GT 配方 |
| --- | --- |
| 基础伏打电堆 | LV 电池外壳 + 4 基础板 + 2 铅板 + 2 红石 + LV 电路 |
| 高级伏打电堆 | 基础伏打电堆 + 4 高级板 + 2 铝板 + 2 红石 + MV 电路 |
| 贫铀伏打电堆 | 高级伏打电堆 + 4 DU 板 + 2 不锈钢板 + 2 铅板 + HV 电路 |
| 精英伏打电堆 | 贫铀伏打电堆 + 4 精英板 + 2 钛板 + 2 钨板 + EV 电路 |
| 锂离子电池 | HV 电池外壳 + 2 铝板 + 2 锂粉 + 1 碳粉 + HV 电路 |
| 基础锂离子电池块 | HV 电池外壳 + 4 高级板 + 4 锂离子电池 + 2 铝板 + HV 电路 |
| 高级锂离子电池块 | 基础电池块 + 4 精英板 + 4 锂离子电池 + 2 不锈钢板 + EV 电路 |
| 贫铀锂离子电池块 | 高级电池块 + 4 精英板 + 4 锂离子电池 + 2 钨钢板 + IV 电路 |
| 精英锂离子电池块 | 贫铀电池块 + 4 精英板 + 4 锂离子电池 + 2 HSS-E 板 + LuV 电路 |

原有的 9 条 NCO 工作台电池/电池单元配方已经全部移除。

这些移除和新的组装机配方都提前到 `postInit` 执行，早于 JEI 在 `loadComplete` 构建配方列表。
否则 JEI 会缓存旧的工作台配方，看起来像“没变”。

合金炉的 2 输入配方也补全了锭/粉组合：对所有输出为锭的合金炉配方（GT、NCO 以及其他模组
注册的合金），分别生成锭+锭、锭+粉、粉+锭、粉+粉四种输入形态。像 GT 的硅锭使用
`itemSilicon` 而不是 `ingotSilicon`，也会被识别并补上硅粉版本。输出去重后新增
**242 条**合金炉变体。

板材：

- 删除 NCO 原有的 5 条工作台配方（`part`、`part_1`..`part_4`）。
- 基础板：2 铅板 + 2 石墨板 -> 2 基础板，GT 组装机。
- 高级板：2 坚韧合金板 + 2 红石 + 1 基础板 -> 1 高级板。
- DU 板：4 晶体粘结剂粉 + 4 铀-238 + 1 高级板 -> 1 DU 板。
- 精英板：4 晶体粘结剂粉 + 4 硼板 + 1 DU 板 -> 1 精英板。
- 新增合金/形态材料补上 `GENERATE_PLATE`，所以坚韧合金和硼现在有 GT 板，板材链必须先经过 GT 轧板/压板。

### 3.9 太阳能板

NCO 的四块太阳能板原本走工作台：石墨粉、红石、重质测重踏板和 NCO 线圈直接拼成整块面板，
既没有光伏层、封装和汇流，也不经过任何机器。现在四种面板全部改为 GT 组装机配方，并按
NCO 的 5 / 20 / 80 / 320 RF/t 四档对应 LV / MV / HV / EV：

| 面板 | 等级 / EUt | GT 组装机配方 |
| --- | --- | --- |
| 基础太阳能板 | LV / 30 | 4 硅板 + 1 硼粉 + 1 磷粉 + 2 玻璃 + 2 铝板 + 4 细铜线 + 1 硅橡胶板 + LV 电路 |
| 高级太阳能板 | MV / 120 | 2 基础板 + 4 硅板 + 2 碳化硅板 + 2 硼硅玻璃板 + 2 不锈钢板 + 4 细银线 + 1 PTFE 板 + MV 电路 |
| 贫铀太阳能板 | HV / 480 | 2 高级板 + 4 碳化硅板 + 2 铅板 + 2 DU 板 + 2 钛板 + 4 细金线 + HV 电路 |
| 精英太阳能板 | EV / 1920 | 2 贫铀板 + 4 硅板 + 2 碳化硅板 + 2 钨钢板 + 2 PTFE 板 + 4 细铂线 + EV 电路 |

设计含义：

- 硅板是光伏吸收层，硼粉和磷粉分别是 P 型 / N 型掺杂剂，构成 PN 结；基础档用普通玻璃，高级档起改用耐热冲击的硼硅玻璃作盖板；铝/不锈钢/钛/钨钢是边框，细导线是汇流条；
- 硅橡胶和 PTFE 分别承担基础封装与耐候/绝缘背板；
- 电路是旁路二极管和功率调节，不再让面板本身兼任“发电机 + 控制器”；
- 高级和贫铀档加入碳化硅散热板，贫铀档用铅板和 DU 板做辐射屏蔽；
- 精英档用更厚的 GT 硅板叠层、碳化硅散热板和钨钢框架，对应空间级高温/抗辐射组件。

每档消耗 2 块上一级面板，而不是原来的 3 块；因为新增的硅板、碳化硅、屏蔽和铂线已经把成本
抬高，继续用 3 块会让整条链过度膨胀。旧工作台配方按输出物品 ID 全部删除（基础板有
`solar_panel_basic` 与 `solar_panel_basic_1` 两条重复变体，也一并清掉）。

## 4. 验证结果

- 模块边界：72 个文件，0 违规。
- 专用服务器启动并完成导出；CraftTweaker 日志 0 error。
- 导出总计：物品 32169、方块 4763、矿物词典 36736 行、GT 配方 67854、NCO 配方 5439、QMD 配方 863、
  工作台配方 22403。
- 材料目标表：370 条。
- 太阳能板：5 条旧 NCO 工作台配方全部变为 `DummyRecipe`；4 条 GT 组装机配方已导出，
  硅板、碳化硅板、细导线、PTFE、DU 板和 QMD 掺杂硅均正确解析为对应物品。
- 残留统计：

| 表 | 产出（含模组命名空间的行） | 消耗 |
| --- | ---: | ---: |
| GT 配方 | 421 | 434 |
| NCO 配方 | 251 | 206 |
| QMD 配方 | 12 | 28 |

GT 配方里剩余的 NCO/QMD 物品已经全部是反应堆专属或非材料物品：LEU/HEU/MIX/TBU 燃料、
TRISO、碳化物/氮化物/氧化物/ZA 燃料形式、带数字后缀的 NCO 独有核素、NCO 冷却器/裂变端口、
食物/医疗物品、QMD 粒子单元与粒子源。稳定材料、合金、氧化物、化合物、宝石和 GT 已有同位素
都已经收敛到 GT 物品。

启动日志中的 `Invalid amount of recipe inputs` 从数万行降到 4 行，且剩余 4 行来自其他模组的
装配机配方，与本桥无关。

NCO 的配方数从 5303 增长到 5426，是因为新建 GT 材料后，NCO 的 `ingot_former`、`melter` 等
处理器会为新的矿物词典材料名自动镜像配方。这些新增配方由桥统一迁入 GT，当前桥共注册
3522 条 NCO 处理器配方，0 条因槽位跳过。

## 5. 仍未处理

1. 工作台产出和 JEI 重复条目还没有做最终清理。当前只保证机器/配方使用 GT 物品，JEI 仍会列出
   NCO/QMD 的副本。
2. 旧存档里的 NCO/QMD 稳定材料还没有 1:1 转换成 GT 物品的迁移配方。
3. NCO 的氧化物/碳化物/氮化物/ZA 燃料变体仍然保留。Omnifactory 选择删除它们；本项目暂时保留，
   等燃料链平衡确定后再决定是否裁剪。
4. 食物、医疗、冷却器、裂变端口等非材料物品保持 NCO 身份，不建立 GT 材料。
